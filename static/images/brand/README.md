# NamahNest identity

Original vector artwork, licensed under the project's MIT license.

- `namahnest-logo-dark.svg`: transparent wordmark for dark backgrounds.
- `namahnest-logo-light.svg`: transparent wordmark for light backgrounds.
- `namahnest-mark.svg`: transparent standalone website symbol.

The symbol sits before the NamahNest wordmark. Layered browser panels represent
static website kits; code brackets represent source-code ownership. Mint and
violet match the site's existing design. The symbol contains no letter monogram.

Use the symbol alone at small sizes. Keep at least one quarter of its width
as clear space. Website typography uses bundled Inter. Editable SVG wordmarks
use Inter when available, with Arial as a fallback. Font notices are documented
in THIRD_PARTY_NOTICES.md. Software licensing does not establish trademark clearance.
